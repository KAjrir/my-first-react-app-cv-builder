# CV Builder

My first React app, built as part of [The Odin Project](https://www.theodinproject.com/): a CV builder with a live preview.

## Features
- Edit personal information, education and work experience
- Add, edit and remove entries
- Live preview of the CV while you type

## Built with
React, Vite

## Usage
```bash
npm install
npm run dev
```

## What I learned
- Thinking in components and splitting an app into an editor and a preview
- Managing form state with `useState` and controlled inputs
